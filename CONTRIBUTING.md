## Contributing

Branching workflow
- Work on `dev` branch. Create feature branches from `dev` named `feature/<desc>`.
- Open a Pull Request to merge `dev` -> `main` when a feature is ready.

Commit messages
- Use short, descriptive messages. Prefix with type: `feat:`, `fix:`, `chore:`, `docs:`.

Testing & linting
- Run unit tests before opening a PR: `pytest -q`.

Code review
- Request at least one reviewer. Keep PR description concise and list changes.

CI/CD
- We will add GitHub Actions in later iteration. For now, test locally.
